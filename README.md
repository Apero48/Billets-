# Site Web de Voyages Afolabi

Un site web moderne pour la promotion de billets de voyage, offrant une sélection de destinations populaires à travers le monde.

## Contenu

Le site comprend :
- Une page d'accueil avec une section héro attractive
- Une section destinations avec des cartes interactives
- Des suggestions d'activités pour chaque destination
- Un formulaire de contact
- Des animations modernes et un design responsive

## Structure des fichiers

- `index.html` - La page principale du site
- `style.css` - Les styles et animations
- `script.js` - Les interactions et animations JavaScript

## Comment utiliser

1. Ouvrez le fichier `index.html` dans votre navigateur web
2. Naviguez à travers les différentes sections
3. Cliquez sur les boutons "Réserver" pour accéder aux offres de billets

## Technologies utilisées

- HTML5
- CSS3 (avec animations et transitions)
- JavaScript (Vanilla)
- Design Responsive
